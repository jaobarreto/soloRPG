# Avaliações narrativas

As avaliações automatizadas usam respostas simuladas e verificam invariantes
observáveis: mensagens preservadas, conhecimento pessoal, efeitos oficiais,
autonomia, sigilo e retomada. Não avaliam qualidade literária de um modelo externo.

| Caso                         | Evidência exigida                                                      |
| ---------------------------- | ---------------------------------------------------------------------- |
| Theron ataca Naelis          | Vida intacta enquanto aguarda Stunts; dano somente após resolução      |
| Prosa inventa espada/vitória | Texto substituído pela projeção; inventário e objetivo não mudam       |
| Proposta contém dano/patch   | Schema estrito recusa; ação e mensagem permanecem recuperáveis         |
| THINK ou OOC                 | Nenhuma escrita no mundo/conhecimento; propostas com efeitos recusadas |
| NPC presencia conflito       | Associação com evento confirmado persiste na sessão seguinte           |
| IA falha após commit         | Apenas narrador é repetido; mesma consequência, dados e mensagens      |
| Pausa durante geração        | Revisão diverge; nenhuma aplicação/publicação atrasada                 |
| Resumo/encerramento falha    | Transação reverte finalização sem remover eventos ou chat              |

Para avaliação humana futura, usar campanha sintética sem segredos pessoais e conta
free sem billing; registrar modelo, data, quota, tokens, latência e qualidade. Testar
diálogos naturais e desvios fora das opções preparadas somente depois de existir uma
política verificável para esses novos fatos. Não marcar o Mestre como completo por
produzir prosa convincente ou por retornar JSON válido.
