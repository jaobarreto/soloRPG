# Menções como referências autorizadas

01/11/2026. O composer mantém linguagem livre e acrescenta referências selecionadas: @ para personagens, # para inventário e objetos interativos. O NestJS constrói o catálogo autorizado e revalida identidade, tipo, rótulo e contexto antes de interpretar e antes de executar. Uma referência não concede presença, comunicação remota, consentimento ou efeito mecânico. O motor continua validando capacidades.

O payload opcional mentions registra tipo, UUID autorizado, label, literal e intervalo [start,end) em unidades UTF-16. Preservamos o texto sem trim para que emoji, acentos e espaços não desloquem intervalos. Spans sobrepostos/inconsistentes são recusados; repetir a mesma entidade em posições distintas é permitido. Editar um token invalida sua associação; editar antes desloca os spans preservados. O Python valida o espelho do contrato, mas devolve nomes; o servidor mantém os UUIDs resolvidos e recusa substituição ou homônimo ambíguo. Referências múltiplas não autorizam um lote de efeitos.

O autocomplete retorna no máximo 20 entradas; busca ignora caixa/acentos. Prioridade: presença/inventário, objetos acessíveis, personagens conhecidos ausentes. Homônimos usam contexto público e descrição pública disponível. Archetypes, personagens desconhecidos, objetos privados/inacessíveis e inventários alheios não são listados. Não se inventam objetos a partir dos textos dos Story Cards. O schema atual não localiza objetos por sala: accessible é a autorização explícita do operador para esse contexto.

Menções usam exclusivamente o fluxo FREE; não podem ser combinadas no mesmo payload com optionId/mechanic. Mensagens anteriores sem mentions continuam válidas. NARRATE recebe a projeção pública existente, sem catálogo ou segredos adicionais. Sem migration: referências selecionadas persistem nos metadados da mensagem e integram o hash de idempotência. Instalar contratos/NestJS e Python compatíveis antes do web; reverter web primeiro e drenar turnos antes de voltar serviços. Manter as definições v3 registradas enquanto existirem campanhas v3.
